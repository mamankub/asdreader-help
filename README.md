# ASDReader — คู่มือ ช่วยเหลือ และดาวน์โหลด

เว็บไซต์: https://mamankub.github.io/asdreader-help/

repository นี้เป็นที่เผยแพร่ของ ASDReader สำหรับทุกคน

- **หน้าเว็บภาษาไทย** (GitHub Pages): หน้าแรก, ดาวน์โหลด, คู่มือ, ช่วยเหลือ, มีอะไรใหม่
- **Releases**: ไฟล์ติดตั้ง Windows (MSI), รุ่นพกพา และ Linux ของแต่ละรุ่น
- **Issues**: สอบถามและแจ้งปัญหา

แก้ไขหน้าเว็บได้ที่ไฟล์ `.md` ในโฟลเดอร์นี้ GitHub Pages สร้างเว็บจาก branch `main` ให้อัตโนมัติ
ภาพหน้าจอใน `assets/images/` มาจากโปรแกรม ASDReader
