# ช่วยเหลือ

## คำถามที่พบบ่อย

### Windows ขึ้นว่า "Windows protected your PC" ตอนติดตั้ง

ไฟล์ติดตั้งยังไม่มีลายเซ็นดิจิทัล ตรวจค่า SHA-256 ของไฟล์ตาม [หน้าดาวน์โหลด](../download/#ตรวจความถูกต้องของไฟล์)
แล้วกด **More info ▸ Run anyway**

### ต้องการติดตั้งไว้ที่ไดรฟ์อื่น

ในตัวติดตั้ง หน้า **Choose the install folder** กด **Browse...** แล้วเลือกโฟลเดอร์
ค่าเริ่มต้นคือ `C:\Program Files\ASDReader`

### แก้ไขข้อความไทยแล้วตัวอักษรบางตัวขึ้นข้อผิดพลาด

ฟอนต์ที่ฝังในไฟล์มีเฉพาะตัวอักษรที่เอกสารใช้ ASDReader จะหาฟอนต์ตัวเต็มชื่อเดียวกันในเครื่องให้อัตโนมัติ
ถ้ายังขึ้นข้อผิดพลาด ให้ติดตั้งฟอนต์นั้น (ข้อความแจ้งเตือนจะบอกชื่อตัวอักษรที่ขาด)
หรือเลือก **แบบอักษรที่ติดตั้ง…** ในแผง **จัดรูปแบบข้อความ** ดู [คู่มือ: ภาษาไทยและฟอนต์](../manual/#ภาษาไทยและฟอนต์)

### หาฟอนต์ของฉันในรายการไม่เจอ

รายการแสดงเฉพาะฟอนต์ที่อนุญาตให้ฝังลงเอกสาร ฟอนต์แบบ variable font และฟอนต์บางตระกูลที่โปรแกรมไม่รองรับจะไม่แสดง
ลองพิมพ์ชื่อในช่อง **ค้นหาแบบอักษร** หรือใช้ **โหลดแบบอักษร…** เลือกไฟล์ฟอนต์โดยตรง

### พิมพ์ออกมาไม่คมชัด

ตั้งความละเอียดและคุณภาพที่ **Printing Preferences** ของเครื่องพิมพ์ใน Windows ASDReader ใช้ค่านั้นกับงานพิมพ์
ถ้าเปิด **พิมพ์เป็นรูปภาพ** อยู่ ให้เลือกความละเอียดที่สูงขึ้นหรือปิดตัวเลือกนี้

### เมนูของโปรแกรมไม่เป็นภาษาไทย

เปิด **การตั้งค่า… ▸ ภาษาของโปรแกรม** แล้วเลือก ภาษาไทย

## แจ้งปัญหาหรือสอบถาม

แจ้งได้ที่ **[GitHub Issues](https://github.com/mamankub/asdreader-help/issues/new/choose)** (ต้องมีบัญชี GitHub)
โปรดระบุ

1. รุ่นของ ASDReader (**วิธีใช้ ▸ เกี่ยวกับ**) และรุ่นของ Windows
2. ขั้นตอนที่ทำให้เกิดปัญหา และผลที่คาดไว้
3. ภาพหน้าจอหรือข้อความแจ้งเตือน

<p class="note"><strong>อย่าแนบเอกสารที่มีข้อมูลส่วนตัวหรือข้อมูลลับ</strong> ข้อมูลใน Issues เปิดให้ทุกคนอ่าน
ถ้าปัญหาเกิดกับไฟล์เฉพาะ ให้ลองสร้างไฟล์ตัวอย่างที่ไม่มีข้อมูลสำคัญแต่ยังเกิดปัญหาเดิม</p>

### ไฟล์บันทึกการทำงาน (log)

ไฟล์ `asdreader.log` ช่วยหาสาเหตุของปัญหาได้ (ไม่มีเนื้อหาเอกสาร แต่อาจมีชื่อไฟล์) อยู่ในโฟลเดอร์ `logs`
ของข้อมูลโปรแกรม

- ติดตั้งด้วยตัวติดตั้ง: ใต้โฟลเดอร์ `%APPDATA%\ASDReader`
- รุ่นพกพา: ในโฟลเดอร์ `ASDReaderData` ข้าง `ASDReader.exe`

โปรแกรมเก็บไฟล์ของการเปิดครั้งก่อนไว้เป็น `asdreader.1.log` ด้วย

## ความเป็นส่วนตัว

- ASDReader ทำงานบนเครื่องของคุณทั้งหมด ไม่อัปโหลดเอกสาร
- โปรแกรมเชื่อมต่ออินเทอร์เน็ตเฉพาะเมื่อคุณสั่ง **ตรวจหาการอัปเดต** หรือคลิกลิงก์
