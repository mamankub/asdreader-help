# มีอะไรใหม่

## v0.13.5

- **ส่งออกเป็นรูปภาพ (PNG, JPEG, TIFF) ได้ความละเอียดตามที่ตั้ง แม้แบบแปลนจะใหญ่มาก**: แผ่น A0L2 (841 × 2378 มม.)
  ส่งออกได้ถึง 600 dpi ทั้งสามรูปแบบ เดิมแผ่นใหญ่ออกมาได้แค่ราว 125 pixels/inch ไม่ว่าจะตั้งเท่าไร
- ไฟล์ PNG ที่ส่งออกบันทึกค่าความละเอียด (dpi) ด้วย และสร้าง PDF จาก PNG นั้นได้หน้าขนาดเท่าต้นฉบับ
- JPEG ยาวได้ไม่เกิน 65,535 พิกเซลต่อด้าน (ขีดจำกัดของรูปแบบ) แผ่นที่ยาวกว่านั้นจะได้ JPEG ความละเอียดต่ำลง ส่วน PNG และ TIFF ยังได้ตามที่ตั้ง

## v0.13.4

- **ASD PDF Printer ถามที่เก็บไฟล์**: ทุกครั้งที่พิมพ์ จะมีหน้าต่างบันทึกให้เลือกโฟลเดอร์และชื่อไฟล์ เริ่มที่โฟลเดอร์ล่าสุดที่เลือก
  (ครั้งแรกเป็น `เอกสาร`) และตั้งชื่อตามชื่อเอกสาร กด **ยกเลิก** เพื่อไม่บันทึก
- **เปิดไฟล์ใหญ่ได้เร็วขึ้น** เช่นแบบแปลนขนาดหลายสิบ MB: วาดหน้าด้วยหลายคอร์ แสดงภาพหน้าระหว่างที่กำลังวาด
  ซูมดูเฉพาะส่วนได้เร็วขึ้นมาก และเส้นบางในแบบคมชัดขึ้น
- **แก้ไขข้อความในไฟล์ที่พิมพ์จาก Microsoft Print to PDF** (หน้าแนวนอนที่เก็บเป็นหน้าหมุน) กล่องแก้ไข ขนาดตัวอักษร
  และเคอร์เซอร์อยู่ตรงบรรทัดแล้ว
- เคอร์เซอร์ไม่หยุดระหว่างพยัญชนะกับวรรณยุกต์หรือสระบน-ล่าง ข้อความที่พิมพ์จึงไม่แทรกกลางตัวอักษร
- พิมพ์ภาษาไทยลงในย่อหน้าที่ฟอนต์ในไฟล์ไม่มีภาษาไทย (เช่นเอกสารที่ใช้ฟอนต์ญี่ปุ่น) ใช้ฟอนต์ไทยในเครื่อง
  (Tahoma, TH Sarabun New, Leelawadee) ให้อัตโนมัติ
- ช่อง **ค้นหาแบบอักษร** ใน **แบบอักษรที่ติดตั้ง…** พิมพ์ค้นหาได้แล้ว และฟอนต์ที่ติดตั้งซ้ำแสดงบรรทัดเดียว
- เครื่องมือ **ข้อความ**: คลิกที่ว่างเพื่อจบการแก้ไขย่อหน้า ไม่สร้างกล่องข้อความเปล่าเพิ่มอีก
- ประกาศลิขสิทธิ์ระบุว่า ASDReader พัฒนาต่อจาก PdfCraft และให้เครดิตผู้เขียนเดิมครบถ้วน

## v0.13.3

- **ASD PDF Printer**: เครื่องพิมพ์ในรายการให้เลือกในทุกโปรแกรมของ Windows พิมพ์แล้วได้ไฟล์ PDF ที่มีข้อความไทยถูกต้องครบ
  (ไม้เอก ไม้โท สระอำ สระบน-ล่าง) บันทึกใน `เอกสาร\ASDReader Printed` และเปิดใน ASDReader ให้อัตโนมัติ
- ซ่อมข้อความไทยในไฟล์ที่พิมพ์ด้วย "Microsoft Print to PDF" ได้ด้วยคำสั่ง `asdreader-cli edit … --repair-thai`
- การค้นหาและคัดลอกข้อความไทยอ่านสระอำที่ถูกแยกส่วน ("นํ้า") เป็น "น้ำ"
- ตัวติดตั้งมีตัวเลือกติดตั้ง/ไม่ติดตั้ง ASD PDF Printer
- **ตัวติดตั้ง Windows เลือกโฟลเดอร์ได้** หน้า **Choose the install folder** พร้อมปุ่ม **Browse...** (ค่าเริ่มต้น `C:\Program Files\ASDReader`)
- **แก้ไขข้อความไทยในไฟล์ที่ใช้ฟอนต์ไทยแบบเก่า** (TH SarabunPSK, Cordia, Angsana ฯลฯ) วรรณยุกต์ไม่หายและอยู่ตำแหน่งเดิมเมื่อบันทึก
- การค้นหาและคัดลอกข้อความไทยเรียงสระและวรรณยุกต์ถูกต้อง
- แก้ไขข้อความในไฟล์จากโปรแกรมเขียนแบบ (หน้าหมุน) และเลือกฟอนต์ให้ย่อหน้าเหล่านั้นได้
- ใช้ฟอนต์ตัวเต็มที่ติดตั้งในเครื่องให้อัตโนมัติ เมื่อพิมพ์ตัวอักษรที่ฟอนต์ในไฟล์ไม่มี
- รายการ **แบบอักษรที่ติดตั้ง…** รวมฟอนต์ในไฟล์ `.ttc` (Cordia New, Angsana New ฯลฯ)
- ลิงก์ช่วยเหลือ คู่มือ และการตรวจหาการอัปเดตในโปรแกรมชี้มาที่เว็บไซต์นี้

## v0.13.2

- เปลี่ยนชื่อโปรแกรมเป็น `ASDReader.exe`
- ตัวติดตั้ง Windows แบบ wizard (MSI)
- ข้อความไทยในเมนูใช้ฟอนต์ไทยแบบมีหัวที่ติดตั้งในเครื่อง
- เลือกฟอนต์ที่ติดตั้งในเครื่องได้เมื่อแก้ไขข้อความ
- งานพิมพ์บน Windows ใช้ค่าความละเอียดจาก Printing Preferences ของเครื่องพิมพ์

## v0.13.1
