# มีอะไรใหม่

## v0.13.3

- **ASD PDF Printer**: เครื่องพิมพ์ในรายการให้เลือกในทุกโปรแกรมของ Windows พิมพ์แล้วได้ไฟล์ PDF ที่มีข้อความไทยถูกต้องครบ
  (ไม้เอก ไม้โท สระอำ สระบน-ล่าง) บันทึกใน `เอกสาร\ASDReader Printed` และเปิดใน ASDReader ให้อัตโนมัติ
- ซ่อมข้อความไทยในไฟล์ที่พิมพ์ด้วย "Microsoft Print to PDF" ได้ด้วยคำสั่ง `asdreader-cli edit … --repair-thai`
- การค้นหาและคัดลอกข้อความไทยอ่านสระอำที่ถูกแยกส่วน ("นํ้า") เป็น "น้ำ"
- ตัวติดตั้งมีตัวเลือกติดตั้ง/ไม่ติดตั้ง ASD PDF Printer
- **ตัวติดตั้ง Windows เลือกโฟลเดอร์ได้** หน้า **Choose the install folder** พร้อมปุ่ม **Browse...** (ค่าเริ่มต้น `C:\Program Files\ASDReader`)
- **แก้ไขข้อความไทยในไฟล์ที่ใช้ฟอนต์ไทยแบบเก่า** (TH SarabunPSK, Cordia, Angsana ฯลฯ) วรรณยุกต์ไม่หายและอยู่ตำแหน่งเดิมเมื่อบันทึก
- การค้นหาและคัดลอกข้อความไทยเรียงสระและวรรณยุกต์ถูกต้อง
- แก้ไขข้อความในไฟล์จากโปรแกรมเขียนแบบ (หน้าหมุน) และเลือกฟอนต์ให้ย่อหน้าเหล่านั้นได้
- ใช้ฟอนต์ตัวเต็มที่ติดตั้งในเครื่องให้อัตโนมัติ เมื่อพิมพ์ตัวอักษรที่ฟอนต์ในไฟล์ไม่มี
- รายการ **แบบอักษรที่ติดตั้ง…** รวมฟอนต์ในไฟล์ `.ttc` (Cordia New, Angsana New ฯลฯ)
- ลิงก์ช่วยเหลือ คู่มือ และการตรวจหาการอัปเดตในโปรแกรมชี้มาที่เว็บไซต์นี้

## v0.13.2

- เปลี่ยนชื่อโปรแกรมเป็น `ASDReader.exe`
- ตัวติดตั้ง Windows แบบ wizard (MSI)
- ข้อความไทยในเมนูใช้ฟอนต์ไทยแบบมีหัวที่ติดตั้งในเครื่อง
- เลือกฟอนต์ที่ติดตั้งในเครื่องได้เมื่อแก้ไขข้อความ
- งานพิมพ์บน Windows ใช้ค่าความละเอียดจาก Printing Preferences ของเครื่องพิมพ์

## v0.13.1

- รุ่นแรกของ ASDReader: โลโก้ใหม่ ปรับข้อความภาษาไทย และฝังฟอนต์ไทยในโปรแกรม
